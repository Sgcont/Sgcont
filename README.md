## 🚀 Projetos

### 🚌 Transportes Rio

Projeto de Banco de Dados sobre transporte público do Rio de Janeiro, envolvendo linhas, viagens, paradas, bairros, tarifas e dados geográficos.

**Python · SQL · SQLite · Pandas · GeoPandas**

### 📊 COCADA

Análise de dados sobre ocorrências criminais no Rio de Janeiro utilizando **SVD, PCA e K-Means** para explorar padrões nos dados.

**Python · Pandas · NumPy · Scikit-Learn**

### 🚗 Acidentes de Trânsito

Projeto do **OASIS** para analisar acidentes no Rio de Janeiro relacionando localização das ocorrências, hospitais próximos e condições climáticas.

**Python · SQL · GeoPandas · Pandas · Machine Learning**

### 🧮 Introdução ao Cálculo

Projeto relacionado à monitoria de Cálculo I, envolvendo análise de desempenho acadêmico e desenvolvimento de ferramentas para estudantes.

**Python · Streamlit · Pandas**
